Markdown语法学习

标题

Markdown用 # 表示标题，1到6个 # 对应不同级别（惊，竟然整整有6个）：

这是一级标题

这是二级标题

这是三级标题

…

文字格式

  • 加粗：在文本两侧分别添加两个星号 **文字**
  • 斜体：在文本两侧分别添加一个星号 *文字*
  • 行内代码：在代码两侧分别添加一个反引号（要注意反引号和普通引号的区别） `代码` ，比如 hexo server

插入超链接

语法格式： [超链接显示名](超链接地址 "超链接title") ,其中，“超链接title”是当鼠标悬停在链接上时会出现的文字，这个title是可选的，它放在圆括号中链接地址后面，跟链接地址之间以空格分隔。
例如：Markdown里编写 [Markdown链接语法教程](https://markdown.com.cn/basic-syntax/links.html "Hello！") （你现在看到的效果是我将其编写变成的行内代码），博客部署后在网页里就会渲染成Markdown链接语法教程

插入图片

语法格式： ![图片alt](图片链接 "图片title") 。“图片alt”是当由于各种原因图片无法加载时会显现出来的文本，“图片链接”有两种，本地图片的文件路径与网络图片的网络链接。对于前者，文件路径分为绝对路径与相对路径，考虑到项目的可移植性与Hexo兼容性，推荐使用相对路径，可在Markdown文件存储路径 D:\blog_library\myblog\source\_posts 下创建一个与博客文件名同名的文件夹，里面放上本篇博客需要的图片，然后编写 ![这是图片](你的博客名称/图片名称.扩展名 "图片title") 即可，“图片title”的作用和上文的“超链接title”类似，这里不在赘述。

目录不对导致部署失败

当我终于写完第一篇博客，打开powershell兴高采烈地准备运行三连部署时，就遇到了和下面相同的三段连续重复代码块，虽然不是红色的报错，但是我的博客始终没有更新，于是把输出结果喂给AI怎么回事，最后才知道是Hexo没有找到博客文件，需要先进入 D:\blog_library\myblog 再运行部署命令就可以了。
