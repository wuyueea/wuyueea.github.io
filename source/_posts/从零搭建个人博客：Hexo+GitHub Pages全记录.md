以下是我的具体步骤——基于Windows系统：


## 环境准备
### 安装Node.js与Git
分别前往官方网站[Node.js 官网](https://nodejs.org/zh-cn)和[Git 官网](https://git-scm.com/)下载安装包，按默认选项完成安装。
然后在powershell一行行运行版本查看脚本测试安装是否成功：
```bash
node -v
npm -v
git --version
```
如果和下面一样返回类似的版本号格式就表明安装成功了，可以进入下一步了；若不成功，可将错误直接发给AI排查。
{% asset_img 环境安装测试.png "环境安装测试截图" %}

### 安装Hexo
直接在powershell运行安装代码：
```bash
npm install -g hexo-cli
```
同样的，安装完毕后，运行版本查看代码测试安装是否成功：
```bash
hexo -v
```
如果和下面一样返回一系列组件的版本号就表明安装成功啦，至此，全部工具已经配置完成，可以正式考虑博客相关事项了。
{% asset_img Hexo安装测试.png "Hexo安装测试截图" %}


## 初始化 Hexo 项目
首先，在这之前，想好一个专门存放博客资源的文件夹，我选择在D盘建了一个名为“blog_library”的文件夹来存放资源。
然后，在powershell一行行运行下面这几条命令来初始化第一个Hexo博客：
```bash
cd D:\blog_library
hexo init myblog
cd myblog
npm install
```
`cd D:\blog_library`：进入之前选择存放资源的文件夹（注意：代码后面的路径要修改为你自己选择的文件夹路径）。
`hexo init myblog`：会创建一个名为`myblog`的新文件夹，这里面就是你的博客全部文件。
`cd myblog`：进入这个新创建的文件夹。
`npm install`：安装Hexo运行所需的各种依赖包。
安装完成后，可以立马在本地看看效果。运行以下命令：
```bash
hexo server
```
然后打开浏览器，访问`http://localhost:4000/`。如果看到Hexo的默认页面，就说明本地博客搭建成功！（结束后回到powershell，根据英文提示，按Ctrl+C退出运行）


## 关联 GitHub 并部署
本地看没什么问题后，就可以正式部署到GitHub Pages上了。
（1）创建GitHub仓库：登录GitHub账号，新建一个仓库（Repository）。仓库名称必须严格遵守`你的GitHub用户名.github.io`的格式，比如你的用户名是`john`，仓库名就要是`john.github.io`。这个命名一旦出错，后面就无法正常访问了，另外提一嘴，你的用户名就是你的账户名，注意是账户而不是昵称，设置里面可以看。为了后续推送顺利，创建新仓库时，不要勾选“Add a README file”等初始化选项，我们要的是一个完全空白的仓库。
（2）配置一键部署：为了能一键将博客推送到GitHub，需要安装一个部署插件，在博客根目录（`myblog`文件夹）下执行（由于前面已经运行过`cd D:\blog_library`和`cd myblog`，所以不用额外运行目录设置）：
```bash
npm install hexo-deployer-git --save
```
（3）关联你的仓库：用文本编辑器（我直接用windows自带的记事本）打开博客根目录下的`_config.yml`文件（这是整个Hexo博客最核心的配置文件），找到文件末尾的`deploy`部分，修改成这样：
```yaml
# 注意：所有冒号后面都有一个英文空格，格式千万不要错
deploy:
  type: git
  repo: https://github.com/你的用户名/你的用户名.github.io.git  # 替换成你自己的仓库地址
  branch: main # 现在GitHub的默认分支大多是main
```
（4）执行部署：所有配置完成后，在终端执行下面的“三连”命令，就能完成最后的部署了。
```bash
hexo clean && hexo generate && hexo deploy
```
如果最后看到`INFO Deploy done: git`的提示，就代表部署成功了！这时，访问`https://你的用户名.github.io`就可以看到你的线上博客了。


## 写作与发布
前述的所有操作自动生成了“Hello world”的默认博客，至此，整个流程基本跑通了。下面就是撰写自己的博客了：
（1）新建文章：powershell运行`hexo new "文章标题"`（运行前文章标题自行更改），运行后就可以在`myblog/source/_posts`看到新生成的markdown文件。
（2）编辑文章：然后就是正式的博客撰写了，我的第一篇文章（也就是这篇）是直接使用记事本编辑的，具体的撰写细节（如其他好用的编辑器、markdown语法等等）自行搜索以及询问AI，在此不作过多赘述。
（3）发布文章：编辑并保存好文章后，再次运行部署的三连命令即可：
```bash
hexo clean && hexo generate && hexo deploy
```


## 途中踩过的坑
（1）运行`hexo init myblog`报错`Failed to connect to github.com port 443`和`EPERM: operation not permitted, mkdir 'D:\'`，前者是网络问题，访问Github失败，我的解决办法是挂梯子；后者是文件夹写入权限不足，这个主要是运行这条命令前我进入的目录是直接在D盘根目录，后续的解决办法就是本博客中改进后的路径，在D盘自己建一个文件夹。
（2）运行`hexo deploy`报错`Author identity unknown`，说明安装Git后还没有配置用户信息，后续的解决办法是powershell运行：
```bash
git config --global user.name "你的GitHub用户名"
git config --global user.email "你注册GitHub用的邮箱"
```
注意：将代码里面引号包含的信息改成自己的信息，英文引号不要删除。
用户信息配置好后，重新运行部署命令。
```bash
hexo deploy
```
